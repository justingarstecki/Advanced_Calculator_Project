# Contributing

Thank you for your interest in contributing to Advanced Calculator Project!

## How to Contribute
1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Submit a pull request describing your changes.

## Contribution Guidelines
- Write clear, readable C++ code.
- Follow consistent naming and formatting.
- Include comments when they help explain complex logic.
- Test changes before submitting a pull request.
- Keep contributions focused on improving the calculator.
